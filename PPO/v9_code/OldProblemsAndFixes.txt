train.py — 3 changes to fix asymmetric learning
Per-agent PPO epochs (PPO_EPOCHS = {"hunter": 3, "prey": 8}): The prey gets 2.7× more gradient steps per rollout. The hunter's simple pursuit task converges fine with 3 epochs. The prey's complex evasion task needs more passes over the data to extract tactical signals.
Hunter freezing (first 20% of training): During the first 2M steps, the hunter's policy is not updated. The prey trains alone against a random (untrained) hunter that moves erratically. Once the freeze lifts at 20%, the hunter starts learning pursuit from scratch — but now the prey already has a head start with wall-avoidance and obstacle-awareness baked in.
Larger prey network (HIDDEN = {"hunter": 128, "prey": 192}): 50% more capacity for the prey to represent complex evasion strategies (dodge, juke, cover-seek, wall-avoid) vs the hunter's simpler pursuit policy.
