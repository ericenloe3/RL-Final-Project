Here's what changed (only my_game_env.py):
Escape nudge in _try_move (new case 4): When both axis-slide attempts also fail, the agent now tries all 8 cardinal/diagonal directions, sorted by dot-product with the intended action so it picks the closest unblocked direction to where it actually wants to go. It uses half-speed so the nudge is subtle. True total freezes now only happen if all 8 directions plus the original are blocked — essentially impossible in this env geometry.
Stuck counter in observations (obs_dim: 62 → 64): Two new floats appended to each agent's observation: its own stuck counter and the opponent's, both normalised to [0, 1] over 30 steps. The policy can now see that it hasn't moved and learn to react — without this, the network has no gradient signal to break from a wall-hugging equilibrium.
Escalating stuck penalty (R_STUCK_SCALE = 0.15): Every step an agent hasn't moved, it pays 0.15 × stuck_steps extra. After 5 stuck steps that's −0.75/step, after 10 it's −1.5/step — quickly overwhelming the survival bonus that was making the prey comfortably camp a corner.
Prey wall penalty tripled (R_WALL_PENALTY_PREY = 3.0 vs hunter's 0.8): The prey was learning that the wall reduced attack angles enough to be worth the small penalty. At 3.0 with WALL_MARGIN widened to 80px, staying within 80px of a boundary costs up to −3.0/step — more than the entire survival budget.
MAX_TIMESTEPS = 500 — you'll need to retrain from scratch since the observation space changed size (64 vs 62).
